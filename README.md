# TUMuch_coffee
City Simulator for Urban Planners that will allow them to simulate different proposals and see the impact of the proposal on the city.  MVP: Creation of a 3d map that allows user to add different objects or remove them and see the impact on the pollution, temperature, etc.


# How to Run

Run `pip install -r requirements.txt`
